# Practical Work №5

## Organization of a GitHub Repository

This repository was created as part of Practical Work №5.
The purpose of this work is to study the basic principles of using
the Git version control system and the GitHub platform.

The repository demonstrates:
- creation of a project repository;
- work with multiple branches;
- adding files of different formats;
- performing commits;
- creating a fork of a public repository.

All actions were performed using the web interface of GitHub.
